プレゼンやダッシュボード、長時間のダウンロード中に画面がスリープしてしまうのを防ぎます。KeepActive は Chrome の実行中は画面をスリープさせず、あなたが設定したスケジュールに従ってのみ、人間らしいゆるやかな操作を Web 版 Microsoft Teams に送ります。キーボードやマウスに触れた瞬間、KeepActive は自動的に手を引きます。

こんな用途で使われています

• 常時表示しておきたいプレゼン、ダッシュボード、監視画面。
• 長時間のダウンロード、レンダリング、アップロード、読書。
• 長い待機作業中に、Web 版 Teams のタブがアイドル状態になるのを防ぐ。

主な機能

• 画面をスリープさせない: KeepActive の動作中、Chrome が起動している間はディスプレイを点灯したままにするよう Chrome に要求します。
• Web 版 Teams のアクティビティ: 既定では 60～150 秒ごとに、ランダムな小さなポインター移動、Shift キーの軽い入力、フォーカス通知を送ります。何もない背景部分へのクリックも任意で追加できます。ボタン、リンク、入力欄はクリックせず、文字入力もメッセージの読み取りも Teams の内容の変更も一切行いません。背景クリックや Teams の各サイトごとの動作はオフにできます。
• 勤務スケジュール: 指定した曜日と時間帯だけ動作します。夜勤などの日をまたぐ時間帯にも対応。
• Smart Pause: パソコンのアイドル検知を利用して、作業中は一時停止し、設定したアイドル時間が経過すると再開します。
• ワンクリックのツールバー操作、Alt+Shift+S ショートカット、セッションの安全上限、ローカル診断。

使い方

1. KeepActive をツールバーにピン留めして、オンにします。
2. Microsoft Teams の Web タブを開いたままにします（通常のタブが最適です）。
3. 必要に応じて、Control Deck で勤務スケジュールと Smart Pause の待機時間を設定します。

プライバシーを最優先

• アカウント登録、分析、広告、トラッキング、サードパーティへの通信は一切ありません。
• 設定と診断データはブラウザープロファイル内（chrome.storage.local）にのみ保存されます。
• このパッケージにネイティブアプリやインストーラーは含まれません。

ご注意

• KeepActive は Microsoft Teams のプレゼンス（在席状況）を保証するものではありません。プレゼンスは Microsoft が管理しています。
• 画面ロック、Intune、グループポリシー、MDM、EDR などの社内の管理機能を回避するものではありません。
• Chrome 116 以降が必要です。画面をスリープさせない機能は Chrome が起動している間のみ動作します。

Microsoft および Microsoft Teams は Microsoft Corporation の商標です。KeepActive は Microsoft とは提携しておらず、Microsoft の承認も受けていません。
