발표, 대시보드, 긴 다운로드 도중에 화면이 꺼지는 일을 막아 보세요. KeepActive는 Chrome이 실행되는 동안 화면이 꺼지지 않게 유지하고, 사용자가 정한 일정에 따라서만 웹 버전 Microsoft Teams에 사람처럼 자연스럽고 부드러운 활동 신호를 보냅니다. 키보드나 마우스를 만지는 순간 바로 물러납니다.

이런 때 사용합니다

• 계속 켜져 있어야 하는 발표 화면, 대시보드, 모니터링 화면.
• 오래 걸리는 다운로드, 렌더링, 업로드, 독서.
• 장시간 수동적인 작업 중에 Teams 웹 탭이 자리 비움 상태가 되지 않게 유지.

주요 기능

• 화면 꺼짐 방지: KeepActive가 켜져 있고 Chrome이 실행 중인 동안 디스플레이를 켜 둔 상태로 유지하도록 Chrome에 요청합니다.
• 웹 Teams 활동: 기본적으로 60~150초마다 무작위의 작은 포인터 이동, Shift 키 입력, 포커스 신호를 보내며, 빈 페이지 배경 클릭도 선택할 수 있습니다. 버튼, 링크, 입력란은 절대 클릭하지 않고, 텍스트를 입력하거나 메시지를 읽거나 Teams 콘텐츠를 변경하지 않습니다. 배경 클릭과 각 Teams 사이트는 개별적으로 끌 수 있습니다.
• 근무 일정: 선택한 요일과 시간에만 작동하며, 야간 근무처럼 자정을 넘기는 시간대도 지원합니다.
• Smart Pause: 컴퓨터의 유휴 상태 신호를 이용해 작업 중에는 일시 중지하고, 설정한 유휴 시간이 지나면 다시 시작합니다.
• 원클릭 툴바 제어, Alt+Shift+S 단축키, 세션 안전 한도, 로컬 진단.

사용 방법

1. KeepActive를 툴바에 고정하고 켭니다.
2. Microsoft Teams 웹 탭을 열어 둡니다(일반 탭이 가장 잘 작동합니다).
3. 선택 사항: Control Deck에서 근무 일정과 Smart Pause 대기 시간을 설정합니다.

개인정보 보호 우선

• 계정, 분석, 광고, 추적, 제3자 요청이 전혀 없습니다.
• 설정과 진단 정보는 브라우저 프로필(chrome.storage.local)에만 저장됩니다.
• 이 패키지에는 네이티브 앱이나 설치 프로그램이 없습니다.

알아 두세요

• KeepActive는 Microsoft Teams의 상태 표시(프레즌스)를 보장하지 않습니다. 프레즌스는 Microsoft가 제어합니다.
• 화면 잠금, Intune, 그룹 정책, MDM, EDR 등 회사의 통제 수단을 우회하지 않습니다.
• Chrome 116 이상이 필요합니다. 화면 꺼짐 방지는 Chrome이 실행 중일 때만 작동합니다.

Microsoft 및 Microsoft Teams는 Microsoft Corporation의 상표입니다. KeepActive는 Microsoft와 제휴 관계가 아니며 Microsoft의 보증을 받지 않았습니다.
